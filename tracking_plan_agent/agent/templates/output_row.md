# 输出行模板（6 列，与历史表同构）

## 使用说明

- 每条埋点需求生成一行；一个需求含多个入口/事件时可生成多行
- 各列内多行内容用换行符分隔
- 整行以制表符连接即为 TSV，可直接粘贴回 WPS

## 模板

| 列 | 内容 |
|---|---|
| 指标名 | 【{功能/迭代名}】{入口/模块名} |
| 指标描述 | {名词短语}点击uv/pv<br>{名词短语}曝光uv/pv |
| 事件 | {平台链接 或 【待建事件：{建议事件名}】 或 "复用已有事件：{原链接}"}<br>{页面}/{组件}<br>{上报要求：曝光和点击都要报 / 仅点击报 / 仅曝光报}<br>参数：<br>{参数名1} {赋值规则（四型之一）}<br>{参数名2} {赋值规则}… |
| 端 | {端列表，顿号分隔：Android、IOS、鸿蒙、Web、小程序、服务端…} |
| 触发类型 | {点击、曝光，顿号分隔，与上报要求一致} |
| 截图说明 | 【待补截图】 |
